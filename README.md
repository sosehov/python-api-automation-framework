# Python API Automation Framework (Pytest)

## Features

- Pytest test suite
- API client layer (`utils/api_client.py`)

- Parametrized tests
- Clean project structure

## Tech

- Python
- pytest
- requests

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
